# Shaithea Alam – Portfolio

A static website: plain HTML, CSS and a little JavaScript. No build step.

```
index.html
css/style.css
js/main.js
images/headshot.jpg
images/dizzy-dreams.jpg
```

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
Upload the folder as-is to any static host (Cloudflare Pages or Workers static assets, GitHub Pages, Netlify, Vercel).
